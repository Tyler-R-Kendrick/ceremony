- AC-42/45: actual installed-PWA/browser cookie boundaries, OS deep links, and physical-device behavior require the external device profile.

- Broader authorization, graph validation, model-hostility, concurrency and storage acceptance invariants require the independently executed Node/HTTP/SDK/Workflow/security evidence. This browser report does not silently certify them.
