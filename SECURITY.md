# Security policy

## Supported versions

Security fixes apply to the default branch (`main`) and to recent releases as tagged. Older untagged snapshots are unsupported.

## Reporting a vulnerability

Report vulnerabilities through GitHub Security Advisories. On the repository, open the Security tab and choose **Report a vulnerability**.

<https://github.com/Tyler-R-Kendrick/ceremony/security/advisories/new>

Do not open a public issue for an unfixed vulnerability. Do not include live credentials, OAuth tokens, vault keys, or connector secrets in the report. Describe impact and a minimal reproduction instead.

Maintainers must enable private vulnerability reporting in repository settings if it is not already on: **Settings → Advanced Security → Private vulnerability reporting**. Until that control is enabled, the report form is not available. Ask [@Tyler-R-Kendrick](https://github.com/Tyler-R-Kendrick) on GitHub to enable it. Do not send vulnerability details in a public issue or comment.

Maintainers acknowledge reports within 3 business days.

## Scope

This project handles authentication ceremonies, credentials, OAuth tokens, vault material, and connector secrets. Reports in that scope are treated seriously.
